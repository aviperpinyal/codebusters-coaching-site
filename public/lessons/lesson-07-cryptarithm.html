Lesson 7

CRYPTARITHM

Solve the arithmetic — find the hidden digits

What is a Cryptarithm?

  • Letters replace digits in an arithmetic problem (addition, subtraction, multiplication)
  • Each letter consistently represents the same digit (0–9)
  • Each digit is represented by exactly one letter
  • Leading letters are never zero
  • Appears as Math (M) at all levels

Classic Example — SEND + MORE = MONEY

The puzzle
  S E N D
+ M O R E
─────────
M O N E Y
Answer: S=9, E=5, N=6, D=7, M=1, O=0, R=8, Y=2 → 9567 + 1085 = 10652

Constraints to Use Immediately

  • Leading digits ≠ 0 — the leftmost letter of any number is not zero
  • If the sum has more digits than either addend, the leading digit of the sum = 1 (it's a carry)
  • In SEND + MORE = MONEY → M = 1 (carry from addition)
  • From M=1 → O is constrained by the thousands column

Solving Strategy

  • 1. Write out columns right-to-left
  • 2. Identify forced values first (leading digit of sum = 1)
  • 3. Work column by column, tracking carry
  • 4. Use modular arithmetic: if D + E ≡ Y (mod 10), only certain (D, E) pairs work
  • 5. Try and eliminate — use a tracking grid of remaining digits
Carry is either 0 or 1 — never more. Use this to constrain each column.

Worked Mini-Example

Puzzle
 A B
+ B A
──────
 C C
  • Units: B + A = C (no carry) or B + A = 10 + C (carry 1)
  • Tens: A + B + carry = C
  • Both columns give C → A + B = C (same sum both ways means carry = 0 in units)
  • CC is a 2-digit repdigit: try C=9, A+B=9, e.g. A=4, B=5 → 45+54=99 ✓

Key Takeaways

  • Each letter = unique digit 0–9; leading letters ≠ 0
  • Carry in each column is 0 or 1
  • Start with forced values (carries, leading-digit-of-sum = 1)
  • Appears as Math (M) — this is the only M-type cipher this year

Exam Practice — Cryptarithm (M)

Each letter = a unique digit 0–9. Leading letters ≠ 0. Zero errors required for full credit.
S E N D
+ M O R E
M O N E Y
  • M must be 1 (it's the carry from adding two 4-digit numbers)
  • O = 0 follows from the carry into the ten-thousands column
  • Work column by column from right to left
  • Decode the word: MONEY

Answer — Cryptarithm: SEND + MORE = MONEY

Solution
S=9   E=5   N=6   D=7   M=1   O=0   R=8   Y=2
9 5 6 7
+ 1 0 8 5
1 0 6 5 2
MONEY = 10652  ·  Verify: 9567 + 1085 = 10652 ✓

Exam Practice — Cryptarithm 2 (M)

Unique digits, leading letters ≠ 0. Decode the word: EVEN
O D D
+ O D D
E V E N
  • EVEN is 4 digits; ODD is 3 — so E = 1 (carry digit)
  • E appears in both thousands and tens positions of EVEN
  • D is the units and tens digit of ODD

Answer — Cryptarithm: ODD + ODD = EVEN

Solution
O=6   D=5   E=1   V=3   N=0
6 5 5
+ 6 5 5
1 3 1 0
EVEN = 1310  ·  Verify: 655 + 655 = 1310 ✓
  • Note: O=8, V=7 also works (855+855=1710). Cryptarithms can have multiple solutions!
