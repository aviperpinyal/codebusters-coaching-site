Lesson 10

NIHILIST SUBSTITUTION

Polybius square + keyword addition

Overview

  • Used by Russian Nihilist revolutionaries in the 1800s
  • Two-step cipher: Polybius square (letter → two digits) + keyword addition
  • At Invitationals/Regionals: Decrypt (D) — key given
  • At State/Nationals: Decrypt or Cryptanalysis (DC)

Step 1 — The Polybius Square

  • A 5×5 grid of letters, labeled 1–5 on rows and columns
  • I and J share one cell (25 letters fit in 5×5)
  • Each letter → a two-digit number (row, column)
Standard Polybius Square
12345
1ABCDE
2FGHI/JK
3LMNOP
4QRSTU
5VWXYZ
  • A=11, B=12, C=13, … Z=55

Keyword Square

  • The keyword is written into the Polybius square first (no duplicate letters)
  • Remaining letters fill in alphabetical order
  • This creates a non-standard Polybius square — the key
Keyword: CODE (no duplicates)
C O D E → then A B F G H I/J K L M N P Q R S T U V W X Y Z

Step 2 — Keyword Addition

  • Convert each plaintext letter to its two-digit Polybius number
  • Write the keyword above the message, repeating
  • Convert each keyword letter to its Polybius number
  • Add the plaintext number and keyword number (no carrying)
Plain: HI    Key: DO
H = 23   I = 24
D = 13   O = 34
Sum: 36   58

Decryption

  • Repeat keyword above ciphertext numbers
  • Convert keyword letters to Polybius numbers
  • Subtract keyword numbers from ciphertext numbers
  • Look up the resulting number in the Polybius square → plaintext letter
If subtraction would give a negative digit, add 10 to the ones place (borrow across columns independently).

Cryptanalysis (State level)

  • Find keyword length using repeated patterns in the ciphertext
  • Group ciphertext numbers by keyword position
  • Use frequency analysis on each group's last digits (column info)
  • The most common Polybius value in English ≈ 23 (H), 15 (E), 44 (T)

Key Takeaways

  • Nihilist = Polybius square coordinates + keyword number addition
  • The keyword sets the Polybius square filling order
  • Decrypt by subtracting keyword numbers from ciphertext numbers
  • D at Invitationals; DC at State
  • Next class: Checkerboard (5×5)

Exam Practice — Nihilist (D)

D-type: both keys given. Subtract keyword Polybius numbers from ciphertext numbers to decrypt.
Polybius keyword: CODE  (square top-right)  ·  Nihilist keyword: KEY
Ciphertext numbers
52 56 68 46 45 65 43 27 68
  • Step 1: Convert KEY to Polybius: K=31, E=14, Y=54 — repeat over the 9 ciphertext numbers
  • Step 2: Subtract each keyword number from the corresponding cipher number
  • Step 3: Look up each result in the Polybius square → plaintext letter

Exam Practice — Nihilist (D) #2

Standard Polybius square (no keyword). Ciphertext may include 3-digit numbers — that's normal.
Nihilist keyword: WIN  ·  5-letter answer
95 58 64 103 39
  • Convert WIN: W=52, I=24, N=33 — repeat as needed
  • Subtract: 95−52, 58−24, 64−33, 103−52, 39−24
  • The 4th number 103 − 52 = 51 — look up 51 in the square
