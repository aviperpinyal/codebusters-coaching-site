Lesson 9

COMPLETE COLUMNAR

Rearrange columns, not letters

What is Transposition?

  • Unlike substitution ciphers, transposition rearranges letters — doesn't replace them
  • The same letters appear in plaintext and ciphertext, just in different order
  • Frequency analysis will show normal English — but words won't appear
  • Complete Columnar appears as Cryptanalysis (C) at all levels

How Columnar Transposition Works

  • Step 1: Write the plaintext in rows under a numeric key
  • Step 2: Number the key letters alphabetically (A=1, B=2, …)
  • Step 3: Read off columns in numeric key order
Key: CARGO (C=1, A=2, R=4, G=3, O=5)

1 2 4 3 5

Completing the Rectangle

  • "Complete" means the grid is a full rectangle — null letters pad the last row if needed
  • The number of rows = ⌈message length / key length⌉
  • Null letters are marked on the test
Read column 1 first, then 2, 3, 4, 5 — always in key-number order.

Encryption — Reading Off Columns

Grid from previous slide (key order: 1=C, 2=A, 3=G, 4=R, 5=O)
Col 1 (C): WCUS
Col 2 (A): EOSX
Col 3 (G): EEEX
Col 4 (R): ADTE
Col 5 (O): EBER
Ciphertext
WCUS EOSX EEEX ADTE EBER

Decryption Process

  • Step 1: Determine key length (given or solve)
  • Step 2: Compute number of rows and which columns are longer (if message doesn't divide evenly)
  • Step 3: Distribute ciphertext back into columns in key-number order
  • Step 4: Read across rows to get plaintext
For C-type: you must figure out the key length. Try lengths 4–8 and see which produces readable text.

Finding Key Length (Cryptanalysis)

  • Try dividing message length by 4, 5, 6, 7, 8 — look for a clean rectangle
  • For each candidate length, rearrange columns and check for English digraphs
  • Once rows look like partial English words, you have the right length
  • Then determine column order by matching common digraphs across adjacent columns

Key Takeaways

  • Columnar transposition rearranges letters — doesn't change them
  • Write in rows, read out in column order (key-number order)
  • Decryption: fill columns in order, read across rows
  • Appears as Cryptanalysis (C) at all levels
  • Next class: Nihilist Substitution

Exam Practice — Columnar Transposition (C)

D-type: keyword given. Write columns in key-rank order, then read across rows.
Keyword: ACE  ·  9-letter ciphertext, no nulls
CEU OSL DRE
  • Key ACE — alphabetical ranks: A=1, C=2, E=3
  • 3 columns, 9 letters → 3 rows. Each segment has 3 letters (one per column)
  • Assign: col A (rank 1) = CEU, col C (rank 2) = OSL, col E (rank 3) = DRE
  • Fill the grid (key order: A C E = cols 1 2 3), then read across rows

Answer — Columnar (D): CODES RULE

Grid (key = ACE, rank order A=1 C=2 E=3)
A   C   E
1   2   3
C   O   D
E   S   R
U   L   E
Read across rows
CODES RULE
Col A=CEU fills column 1; col C=OSL fills column 2; col E=DRE fills column 3 → rows read left-to-right.

Exam Practice — Columnar (C)

C-type: no keyword. Use the crib to identify columns — crib length ≥ key length − 1.
Key length: 4  ·  Crib: first 4 plaintext letters = FIND
Ciphertext (12 letters, no nulls)
IHC DLS FTO NEK
  • 12 letters ÷ 4 cols = 3 rows: split ciphertext into 4 segments of 3: IHC · DLS · FTO · NEK
  • Crib FIND fills row 1: F, I, N, D each start a different segment
  • Match each crib letter to the segment it starts — that tells you each column's rank order

Answer — Columnar (C): FIND THE LOCKS

Crib matching: FIND → rank order of columns
F → FTO (rank 3)   I → IHC (rank 1)   N → NEK (rank 4)   D → DLS (rank 2)
