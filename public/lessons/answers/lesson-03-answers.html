Exam Q1 — Solution

Decode all 15 letters
O→S E→C A→I U→E I→N = SCIEN
E→C U→E J→O G→L X→Y = CEOLY
H→M K→P A→I F→A Q→D = MPIAD
Raw string → find word breaks
SCIENCEOLYMPIAD → SCIENCE OLYMPIAD
Answer
SCIENCE OLYMPIAD
Teaching note: the word break isn't given — students must recognize SCIENCE and OLYMPIAD from the letter run. This is harder than Aristocrat where spaces help.

Exam Q2 — Patristocrat (C) · Problem

C-type · Crib: THE = PYU · 17 letters (3 full groups + 2)
EJQUO YAQUP YUPMS PY
  • PYU spans the group 2/3 boundary: P is the 5th letter of YAQUP, Y and U start YUPMS.

Exam Q2 — Solution

Crack path
PYU=THE (spans groups 2–3) → T=P, H=Y, E=U
EJQUO: E=C, J=O, Q=D, U=E, O=S → CODES
YAQUP: Y=H (from H=Y), A=I, Q=D (from D=Q), U=E, P=T → HIDET
YUPMS: Y=H, U=E, P=T, M=R, S=U → HETRU
PY: P=T, Y=H → TH
Raw: CODESHIDETHETRUTH
Answer
CODES HIDE THE TRUTH

HW 3 — Patristocrat (C) · Problem

C-type · Crib: CODES = EJQUO (last 5 letters)
RMUFD EJQUO

HW 3 — Solution

Crack path
EJQUO=CODES (crib) → C=E, O=J, D=Q, E=U, S=O
RMUFD: R=?, M=?, U=E, F=?, D=K → _?_EK → try BREAK: R=B, M=R, F=A
Decode
R→B M→R U→E F→A D→K = BREAK
E→C J→O Q→D U→E O→S = CODES
Answer
BREAK CODES

HW 4 — Patristocrat (C) · Problem

C-type · Crib: CRYPT = EMXKP (last 5 letters)
GUFMI EMXKP

HW 4 — Solution

Crack path
EMXKP=CRYPT (crib) → C=E, R=M, Y=X, P=K, T=P
GUFMI: G=?, U=E, F=?, M=R, I=? → _E_R_ → try LEARN: G=L, F=A, I=N
Decode
G→L U→E F→A M→R I→N = LEARN
E→C M→R Y→? wait: X→Y (from Y=X), K→P, P→T
E→C M→R X→Y K→P P→T = CRYPT
Answer
LEARN CRYPT
Teaching note: GUFMI → the U=E and M=R mappings from the CRYPT crib directly constrain the first group. This shows how a single good crib can unlock the whole message.
