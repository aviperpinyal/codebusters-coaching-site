Lesson 2 — Answer Key

ARISTOCRAT

Coach use only — do not distribute to students

Coach Notes — How These Ciphers Were Built

  • K1 or random only. The 2027 rules allow only K1 or random alphabets for Aristocrats at Regionals. The key-given problems use a K1 alphabet with keyword WIZARD.
  • No letter maps to itself. The rules forbid it for Aristocrats, Patristocrats, and Xenocrypts. Every alphabet in this lesson was checked.
  • One alphabet per crib problem. Each C-type problem uses its own random alphabet, so the slide 11 key will not solve them.
  • K1 means the keyword goes in the plain row. The cipher row is plain A to Z, which makes decoding a lookup in alphabetical order.

Lesson Walkthrough — Full Solution

GTM PSALW JVBXH YBZ ISEUF BQMV GTM CNOR KBD
Crack path (cipher = plain)
GTM appears twice → THE → G=T, T=H, M=E
BQMV: _ _ E _ → OVER → B=O, Q=V, V=R
YBZ and KBD: _ O _ → FOX, DOG → Y=F, Z=X, K=D, D=G
JVBXH: _ R O _ _ → BROWN → J=B, X=W, H=N
PSALW: THE _ _ _ _ _ BROWN FOX → QUICK → P=Q, S=U, A=I, L=C, W=K
ISEUF: _ U _ _ _ → JUMPS → I=J, E=M, U=P, F=S
CNOR: THE _ _ _ _ DOG → LAZY → C=L, N=A, O=Z, R=Y
Answer
THE QUICK BROWN FOX JUMPS OVER THE LAZY DOG
Teaching note: this sentence uses all 26 letters, so solving it recovers the whole key. Once students recognize the famous phrase, every remaining word falls out.

Exam Q2 — Aristocrat (C) · Problem

C-type · Crib: THE = RGD
RGD DTYMF JOYA LTRLGDQ RGD HXYW
  • Write T over every R, H over every G, and E over every D, then work outward from short words.

Exam Q2 — Solution

Crack path
RGD=THE (crib) → R=T, G=H, D=E
LTRLGDQ: _ _ T _ H E _, 1st and 4th letters match → CATCHES → L=C, T=A, Q=S
DTYMF: E A _ _ _ → EARLY → Y=R, M=L, F=Y
JOYA: _ _ R _ → BIRD → J=B, O=I, A=D
HXYW: _ _ R _ after THE → WORM → H=W, X=O, W=M
Answer
THE EARLY BIRD CATCHES THE WORM
Teaching note: after the crib, attack the word with the most known letters. LTRLGDQ reads _ _ T _ H E _, and its repeated letter points to CATCHES. The new A turns DTYMF into E A _ _ _, which is EARLY.

HW 2 — Aristocrat (C) · Problem

C-type · Crib: THE = XFA
XFA GJRA QK GLTGDAR
  • 4-word answer. QK is a 2-letter word.

HW 2 — Solution

Crack path
XFA=THE (crib) → X=T, F=H, A=E
GJRA: A=E → _ _ _ E → CODE → G=C, J=O, R=D
QK: Q=I, K=S → IS
GLTGDAR: G=C, L=R, T=A, G=C, D=K, A=E, R=D → CRACKED
Answer
THE CODE IS CRACKED
Teaching note: 2-letter words like QK have only a few likely values (IS, IT, IN, OF, OR, AT). GLTGDAR starts and repeats with G, the same first letter as GJRA = CODE, so it begins with C. C _ _ C _ E D points to CRACKED.

HW 3 — Aristocrat (D) · Problem

D-type · Same WIZARD alphabet
QIXIE KBXI WS

HW 3 — Solution

Decode
Q→N   I→E   X→V   I→E   E→R = NEVER
K→G   B→I   X→V   I→E = GIVE
W→U   S→P = UP
Answer
NEVER GIVE UP
Teaching note: in a K1 alphabet the cipher row is in plain A–Z order, so decoding is quick. Find the cipher letter in the bottom row and read the plain letter above it. For example, cipher V sits under plain T.

HW 4 — Aristocrat (C) · Problem

C-type · Crib: WIN = JAI
JAI WXH SYIWHVW
  • 3-word answer. Crib gives J=W, A=I, I=N.

HW 4 — Solution

Crack path
JAI=WIN (crib) → J=W, A=I, I=N
WXH: a 3-letter word after WIN → THE → W=T, X=H, H=E
SYIWHVW: S=C, Y=O, I=N, W=T, H=E, V=S, W=T → CONTEST
Answer
WIN THE CONTEST
Teaching note: each C-type problem uses its own alphabet, just like a real exam. Mappings from one problem do not carry over to another. Here the crib plus a THE guess gives _ _ N T E _ T, and CONTEST fits.
