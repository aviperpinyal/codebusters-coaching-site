HOMOPHONIC

Multiple symbols per letter — defeating frequency analysis

The Problem with Simple Substitution

  • In a standard monoalphabetic cipher, E always maps to the same symbol
  • Frequency analysis immediately exposes E, T, A, O…
  • Homophonic substitution fixes this by giving multiple cipher symbols to common letters
  • Rare letters get fewer symbols; common letters get many

How it Works

  • Each plaintext letter is assigned 1 or more cipher equivalents (homophones)
  • When encrypting, pick any one of that letter's homophones at random
  • The more frequent a letter, the more homophones it gets — flattening frequencies
Example assignment (partial)
E → 7, 14, 22, 35, 41, 56, 63 (7 homophones)
T → 8, 19, 29, 47, 58 (5 homophones)
Z → 99 (1 homophone)

Cipher Symbol Sets

  • Symbols are often two-digit numbers (00–99 gives 100 possible symbols)
  • Total symbols used = 100 (or however many) distributed proportionally to letter frequencies
  • On the test, the cipher might use numbers, symbols, or a combination
The key maps each of the 100 symbols to a plaintext letter. It's always provided for D-type problems.

Decryption (D-type — key given)

  • The key table maps each cipher symbol back to a plaintext letter
  • Look up each ciphertext symbol in the table → write the plaintext letter
  • Multiple different symbols all map to the same letter — that's fine
Decryption is just lookup — the key resolves all ambiguity. Focus on speed.

Cryptanalysis (DC — no key)

  • Count how often each individual symbol appears
  • Group symbols by frequency — all homophones of E will be frequent
  • The total symbol frequencies should match English letter frequencies
  • Try to group symbols into sets that together match E, T, A, O… frequencies
This is hard! Word patterns and partial guesses are your main tool alongside frequency grouping.

Breaking Strategy

  • Step 1: Tally all 100 possible symbols; find which are used
  • Step 2: Sort by frequency; the most frequent symbols are likely E-homophones
  • Step 3: Look for single-symbol words → A or I
  • Step 4: Look for 3-symbol sequences that repeat → likely THE
  • Step 5: Assign letters, check against word boundaries, iterate

Key Takeaways

  • Homophonic = multiple cipher symbols per plaintext letter, distributed by frequency
  • Defeats simple frequency analysis — all symbol frequencies appear roughly equal
  • D-type: look up each symbol in the provided key
  • C-type: group symbols by joint frequency, then use word patterns
  • Appears as DC at all levels

Exam Practice — Homophonic (D)

D-type: full key provided. Same letter can appear as different symbols — just look each one up.
Key excerpt: 05=C   07=D   09=E   12=E   17=H   18=I   28=N   31=O   44=T   67=W
Ciphertext (10 symbols → 10 letters)
67 18 28 44 17 09 05 31 07 12
  • Symbols 09 and 12 both map to E — homophones for the same letter
  • Look up each number in the key, write the letter, restore word spaces

Answer — Homophonic (D): WIN THE CODE

Symbol-by-symbol lookup
67=W   18=I   28=N  |  44=T   17=H   09=E  |  05=C   31=O   07=D   12=E
Plaintext: WIN THE CODE
Note: 09 and 12 both = E — homophones! Different symbols, same letter. This is what makes Homophonic harder to crack without the key.

Answer — Homophonic (D) #2: BREAK CODES

Symbol-by-symbol lookup

Both E symbols (08 and 10) produce the same plaintext letter — homophones are designed to confuse frequency analysis, but the key resolves them instantly.
