Lesson 8

PORTA CIPHER

13-row keyword-driven substitution

Background

  • Invented by Giovanni Battista della Porta (~1563)
  • A polyalphabetic substitution using a 13-row tableau and a repeating keyword
  • At Invitationals/Regionals: Decrypt (key given)
  • At State/Nationals: Decrypt or Cryptanalysis
  • The Porta tableau is always provided on the test

The Porta Tableau

  • 13 rows labeled by key-letter pairs: AB, CD, EF, GH, IJ, KL, MN, OP, QR, ST, UV, WX, YZ
  • Each row contains 13 letters — half the alphabet
  • The remaining 13 letters of the alphabet form the other half
  • The cipher is its own inverse — encrypt and decrypt use the same row
Porta is self-reciprocal: encrypting with the same key decrypts the message.

How to Encrypt

  • Step 1: Write the keyword above the plaintext, repeating as needed
  • Step 2: For each plaintext letter, look up the row corresponding to the current key letter's pair
  • Step 3: Find the plaintext letter's position (top half or bottom half) and swap it with the corresponding letter in the other half
Key: KEY    Plain: HELLO
Key letters: K E Y K E
Plain: H E L L O
Row for K: IJ row → look up H and E …

Decryption (Same Process)

  • Repeat the keyword above the ciphertext
  • For each ciphertext letter, use the same tableau row
  • The result is the plaintext letter directly
Self-reciprocal property makes Porta easier to work with — one procedure for both directions.

Recognizing & Breaking Porta

  • For Cryptanalysis: determine the keyword length using the Kasiski test or IC analysis
  • Once key length is known, group letters by key position and solve each group independently
  • The 13 rows are fixed — once you know which row a group uses, there are only 13 options
In competition, DC problems at State may test your ability to determine the keyword length.

Practice

Apply Porta tableau row for each key letter to each cipher letter

Key Takeaways

  • Porta uses a 13-row tableau and a repeating keyword
  • Self-reciprocal: same tableau + key encrypts and decrypts
  • Tableau is always provided — memorization not needed
  • D at Invitationals; DC at State/Nationals

Keyword: MAPLE  ·  Ciphertext

  • Repeat the keyword above the ciphertext: M A P L E M A P
  • For each cipher letter: find its row (key-letter pair), locate the letter in the tableau, swap halves
  • If cipher letter is in the top half (A–M), it maps to the bottom-half letter in that row's column — and vice versa

Exam Practice — Porta (C)

C-type (State): no keyword given. Use the 3-letter crib to find the keyword, then decrypt.
Crib: first 3 plaintext letters = COD  →  first 3 cipher letters = NKW
Ciphertext (9 letters)
NKW PZM VVF
  • Use crib: N must encrypt C, K must encrypt O, W must encrypt D — find which row and key letter works for each
  • The three key letters spell the keyword (repeating)
  • Answer is 3 words (3+2+3 letters)

Answer — Porta (C): NKW PZM VVF → CODE IS KEY

Crib reveals keyword
N+C: row WX has C→N  →  key letter W
K+O: row IJ has O→K (bottom pos 10 = top pos 10 = K)  →  key letter I
W+D: row MN has D→W  →  key letter N    ∴ keyword = WIN
Full decode (key WIN repeating)
W I N W I N W I N
N K W P Z M V V F
C O D E I S K E Y
Plaintext: CODE IS KEY
