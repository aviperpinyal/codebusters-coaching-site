BACONIAN

Binary encoding disguised as text

Background

  • Invented by Francis Bacon in 1605
  • Each letter is encoded as a 5-character sequence of two symbols — traditionally A and B
  • A precursor to modern binary encoding
  • Also used as steganography — hiding a secret inside an innocent-looking text
  • Appears as Cryptanalysis (C) at all levels — you decode from the pattern

Reading a Baconian Message

  • The ciphertext is a stream of A's and B's grouped into 5-letter chunks
  • Each chunk maps to one plaintext letter
  • Think of A = 0, B = 1 → it's binary!
Ciphertext
AAABA AABAA ABABB ABBAB BAAAB
Decode each group
AAABA=C  AABAA=E  ABABB=M  ABBAB=O  BAAAB=?

Steganographic Version

  • The A/B sequence can be hidden in font changes — bold vs. normal, italic vs. roman
  • Two typefaces represent A and B — the hidden message is in the pattern of typefaces
  • In a test, you may see a block of text with two different fonts — read the pattern!
Group every 5 characters, classify each as "font A" or "font B," look up in the table.

Key Takeaways

  • Baconian = 5-character A/B encoding of each letter (binary!)
  • Look up each 5-character group in the Baconian table
  • May be steganographic — hidden in font differences
  • Appears as Cryptanalysis (C) — no key given, but the table is always provided on the test
