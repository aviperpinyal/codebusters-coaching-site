CODEBUSTERS

Intro to the Event + Caesar & Atbash

What is Codebusters?

  • A Science Olympiad event about encoding and decoding secret messages
  • Three-person teams compete against the clock — 30 minutes per test
  • Questions range from simple decryption (key is given) to full cryptanalysis (no key!)
  • Math-based ciphers (Cryptarithm) also appear
  • We compete at Invitationals, Regionals, and hopefully State

Event Format

  • Written test — paper and pencil, no computers
  • Up to 3 teammates in the room, unlimited collaboration
  • Scoring: points per correct plaintext letter plus bonus for full solves
  • Strategy matters — divide and conquer between teammates

How Class Works

  • Attendance — taken at the start of every session; let a coach know if you can't make it
  • Teams — grouped into 3-person teams, same format as competition; you work and compete together
  • Timed Question — each class opens with a timed team decrypt; fastest correct team solve earns points toward the leaderboard
  • Leaderboard — top scores from timed questions are posted on the team website, updated each week
Team assignments may shift as the season progresses — it depends on who develops strengths in which ciphers.

Key Terms

  • Plaintext — the original readable message
  • Ciphertext — the encoded/scrambled version
  • Encrypt — convert plaintext → ciphertext
  • Decrypt (D) — recover plaintext using the given key
  • Cryptanalysis (C) — break a cipher with no key provided
  • Key — the secret controlling the cipher (a number, word, or table)
  • Crib — a known plaintext hint used to start cracking
  • Monoalphabetic — one fixed substitution rule throughout the whole message
  • Frequency analysis — use letter counts to guess substitutions (E is most common in English)
  • D-type / C-type — key given vs. no key; determines how hard a problem is

What We'll Learn This Year

  • Monoalphabetic — Caesar, Atbash, Aristocrat, Patristocrat
  • Polyalphabetic / Keyed — Porta, Nihilist, Homophonic
  • Transposition — Complete Columnar
  • Encoding / Steganographic — Baconian, Fractionated Morse, Xenocrypt, Checkerboard
  • Math — Cryptarithm

Caesar / Shift Cipher

SHIFT EVERYTHING

Julius Caesar used this to protect military orders (~58 BCE)
"If Caesar had anything confidential to say, he wrote it in cipher — shifting each letter of the alphabet by three."
— Suetonius, De Vita Caesarum, ~121 CE
SPQR

How the Caesar Cipher Works

  • Replace each plaintext letter with the letter N positions later in the alphabet
  • Wrap around: Z + 1 = A
  • The key is the shift amount (0–25)
  • Classic Caesar used shift = 3
Shift = 3
Plain: A B C D E F … X Y Z
Cipher: D E F G H I … A B C

Encrypting with Caesar (shift 3)

Plaintext

W+3 = Z   O+3 = R   R+3 = U   L+3 = O   D+3 = G
Ciphertext
KHOOR ZRUOG

Decrypting Caesar — No Key Given

  • The rules do not provide the shift amount — you find it yourself
  • Only 25 possible shifts — try them all until the plaintext makes sense (brute force)
  • Faster: try the most common shift values first (3, 13) or look for short words like A, I, THE, AND
  • Reverse the shift — subtract N instead of adding; wrap Z+1 = A
Ciphertext — shift unknown
PBQROHFGREF
Try shift 13: subtract 13 from each letter

ATBASH

The mirror cipher — ancient Hebrew origin, ~600 BCE
א ↔ ת    ב ↔ ש
Aleph–Tav  ·  Bet–Shin  ·  first + last letters of the Hebrew alphabet

Atbash Background

א ב ג ד ה ו ז ח ט י כ ל מ נ ס ע פ צ ק ר ש ת
Hebrew aleph-bet (read right-to-left) · Atbash pairs the first letter with the last, and so on
  • One of the oldest ciphers — used in the Hebrew Bible (~600 BCE)
  • Name from Hebrew: Aleph–Tav, Bet–Shin — first↔last, second↔second-to-last
  • English rule: A↔Z, B↔Y, C↔X, … — same idea, reversed alphabet
  • Self-inverse: apply it twice and you're back to the original
  • No secret key — the reverse-alphabet mapping is fixed and always printed on your resource sheet

Key Takeaways

  • Caesar: shift every letter by a fixed amount; shift is not given — try all 25 (brute force)
  • Atbash: reverse the alphabet (A↔Z); no secret key — mapping is fixed, always on your resource sheet
  • Both are monoalphabetic; Caesar requires finding the shift, Atbash requires none
  • Caesar has 25 possible shifts; Atbash has exactly one mapping — memorize it cold
  • Next class: Aristocrat — full scrambled alphabet + cryptanalysis

CODEBUSTERS LOVE CODES
ROT13 (shift = 13) is its own inverse — same operation encrypts and decrypts. P(16) − 13 = 3 = C ✓
  • How to find it: try P − 3 = M (no), P − 13 = C (yes — "CODEBUSTERS" is 11 letters!)
